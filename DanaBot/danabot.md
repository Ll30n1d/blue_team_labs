# DanaBot — CyberDefenders Writeup

## Информация о лабе

- **Платформа:** CyberDefenders
- **Ссылка:** [CyberDefenders — DanaBot](https://cyberdefenders.org/blueteam-ctf-challenges/danabot/)
- **Название:** DanaBot
- **Категория:** Network Forensics / Malware Analysis
- **Сложность:** Easy
- **Формат улик:** PCAP-файл с сетевым трафиком

## Сценарий

В сети зафиксирована подозрительная активность. В роли аналитика нужно разобрать PCAP, найти malicious-файлы, определить процесс запуска и посчитать хеши.

## Инструменты

- Wireshark — анализ PCAP
- `sha256sum` / `md5sum` — вычисление хешей
- VirusTotal / ANY.RUN — проверка хешей и поведения

## Ход решения

### 1. IP-адрес точки входа

Открыл PCAP в Wireshark. Отфильтровал HTTP-трафик (`http.request`). В первых запросах внутренний хост (жертва) обращается к внешнему IP-адресу:

```
62.173.142.148
```

Это ответ на первый вопрос.

### 2. Имя malicious-файла

Кликнул на подозрительный HTTP-запрос → **Follow → HTTP Stream**. В заголовках ответа нашёл поле `Content-Disposition` с именем файла:

```
allegato_708.js
```

Это JavaScript-файл, который сервер отдал жертве. Ответ на второй вопрос.

### 3. SHA-256 файла

В Wireshark: **File → Export Objects → HTTP**. Нашёл объект, соответствующий `allegato_708.js` (или `login.php`), и сохранил его. Посчитал SHA-256:

```bash
sha256sum login.php
```

Результат:

```
847b4ad90b1daba2d9117a8e05776f3f902dda593fb1252289538acf476c4268
```

Это ответ на третий вопрос.

### 4. Процесс запуска

Проверил SHA-256 в VirusTotal / ANY.RUN. В разделе **Behavior** (Process Tree) увидел, что файл запускается через:

```
wscript.exe
```

Это встроенный Windows-скриптовый движок, который используется для запуска JavaScript-файлов. Ответ на четвёртый вопрос.

### 5. Второй malicious-файл

В том же PCAP есть второй подозрительный объект. Вернулся к **File → Export Objects → HTTP** и посмотрел на список ещё раз. Обратил внимание на файл с расширением:

```
.dll
```

Это библиотека Windows, которая скачивается вторым этапом атаки. Ответ на пятый вопрос.

### 6. MD5 второго файла

Сохранил файл `resources.dll` и посчитал MD5:

```bash
md5sum resources.dll
```

Результат:

```
e758e07113016aca55d9eda2b0ffeebe
```

Это ответ на шестой вопрос.

## Выводы

- Атака началась с обращения жертвы к внешнему IP `62.173.142.148`.
- Сервер отдал JavaScript-файл `allegato_708.js`, который запускается через `wscript.exe`.
- Вторым этапом скачивается DLL-библиотека `resources.dll` — модуль банковского трояна DanaBot.
- SHA-256 JS-файла: `847b4ad90b1daba2d9117a8e05776f3f902dda593fb1252289538acf476c4268`
- MD5 DLL-файла: `e758e07113016aca55d9eda2b0ffeebe`

## Что потренировал

- Фильтрация HTTP-трафика в Wireshark
- Работа с HTTP-потоками и извлечение объектов
- Вычисление хешей (SHA-256, MD5)
- Проверка хешей в VirusTotal / ANY.RUN
- Понимание многоступенчатой атаки (JS-дроппер → DLL-модуль)
- Определение процесса запуска через Behavior-анализ
