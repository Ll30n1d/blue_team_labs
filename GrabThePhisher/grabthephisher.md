# GrabThePhisher — CyberDefenders Writeup

## Информация о лабе

- **Платформа:** CyberDefenders
- **Ссылка:** [CyberDefenders — GrabThePhisher](https://cyberdefenders.org/blueteam-ctf-challenges/grabthephisher/)
- **Название:** GrabThePhisher
- **Категория:** Threat Intelligence / Phishing Analysis
- **Сложность:** Easy
- **Формат улик:** Архив с фишинговым китом (исходники поддельного сайта)

## Сценарий

DeFi-платформа подверглась атаке: пользователи вводили seed-фразы на поддельном сайте, копирующем PancakeSwap. В результате были похищены криптоактивы. В роли аналитика нужно разобрать фишинговый кит, найти индикаторы компрометации и выйти на след атакующего.

## Инструменты

- VS Code — просмотр и анализ исходного кода
- `wc -w` — подсчёт слов в лог-файле
- Браузер — просмотр фишинговой страницы
- Telegram Bot API — получение информации о владельце бота

## Ход решения

### 1. Структура фишингового кита

Распаковал архив (пароль — `cyberdefenders.org`). Внутри обнаружил папку `pankewk` (имитация PancakeSwap) с набором файлов:

- HTML-страницы, имитирующие интерфейс кошелька
- PHP-скрипты для обработки введённых данных
- Папка `log` для сохранения seed-фраз

### 2. Определение кошелька и языка

В папке кита нашёл PHP-файл, который запрашивает seed-фразу. По имени папки и файла определил, что имитируется кошелёк **MetaMask**. Код написан на **PHP**.

### 3. Сервис геолокации

В начале PHP-скрипта найдено обращение к внешнему API через `file_get_contents()`. Этот сервис по IP определяет страну и город жертвы. Название сервиса — **sypexgeo**.

### 4. Лог с seed-фразами

В PHP-скрипте найдена функция записи в файл внутри папки `log`. Открыл `log/log.txt`. Внутри — несколько seed-фраз, собранных с жертв.

Подсчёт количества фраз через `wc -w` (с учётом структуры файла) дал **3** фразы. Последняя фраза в логе — та, что была записана позже всех.

### 5. Канал эксфильтрации

В PHP-скрипте найдены переменные для отправки данных через Telegram Bot API:

- **Токен бота** — `$token = "5457463144:AAG8t4k7e2ew3tTi0IBShcWbSia0Irvxm10";`
- **ID чата** — `$id = "5442785564";`

Эти значения используются для отправки украденных данных в Telegram.

### 6. «Союзники» разработчика

В комментариях PHP-файла найден никнейм/email разработчика кита `Regards, j1j1b1s@m3r0`. Это указывает на возможного создателя или распространителя фишингового инструмента.

### 7. Выход на атакующего

Используя токен бота и ID чата, обратился к Telegram Bot API:
https://api.telegram.org/bot<ТОКЕН>/getChat?chat_id=<ID>

В ответе JSON получена информация о владельце бота:

- **Имя и фамилия** владельца
- **Username** в Telegram

Это позволило идентифицировать человека, стоящего за фишинговой кампанией.

## Выводы

- Фишинговый кит имитирует **MetaMask** и распространяется под видом PancakeSwap.
- Сбор seed-фраз ведётся в `log/log.txt`, всего собрано **3** фразы.
- Данные эксфильтрируются через **Telegram Bot API** (токен + ID чата).
- Геолокация жертвы определяется через **sypexgeo**.
- В комментариях кода остался никнейм разработчика — дополнительный след.
- Через Telegram API удалось получить имя и username владельца бота.
